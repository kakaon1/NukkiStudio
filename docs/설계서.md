# Nukki Studio 설계서

- 최초 작성일: 2026-10-06
- 최종 갱신일: 2026-10-06
- 상태: 1차 기능 구현 완료 (v1.0.0)

---

## 1. 용어 정리

| 용어 | 설명 |
|------|------|
| 누끼 | 이미지에서 원하는 **객체만 골라 배경과 분리**하는 작업. 결과는 보통 배경이 투명한 PNG |
| 객체 (Object) | 사람, 동물, 물건 등 이미지 안에서 분리 / 지우기 대상 |
| 세그멘테이션 | 이미지의 각 픽셀이 어떤 대상에 속하는지 구분하는 작업 |
| 인터랙티브 세그멘테이션 | 사용자가 클릭 / 박스로 지정한 객체만 분할하는 방식 (SAM) |
| 객체 감지 (Detection) | 이미지 속 객체의 위치(상자)와 종류를 자동으로 찾는 작업 (D-FINE) |
| 인페인팅 (Inpainting) | 지운 영역을 주변 내용으로 자연스럽게 채우는 작업 (MI-GAN) |
| 프롬프트 | 객체를 지정하는 입력. 포함 점 / 제외 점 / 박스 |
| 마스크 | 픽셀마다 객체인지 아닌지를 나타내는 흑백 이미지. 0 = 배경, 255 = 객체 |
| 페더 | 마스크 경계를 부드럽게 흐리게 하는 처리 |
| 인코더 / 디코더 | SAM의 두 부분. 인코더는 이미지를 한 번 분석(무거움), 디코더는 클릭마다 마스크 생성(가벼움) |
| ONNX | AI 모델 공용 파일 형식. C#에서는 ONNX Runtime으로 실행 |

## 2. 목표와 범위

### 목표

- 이미지를 열고 객체를 **자동으로 찾거나 클릭 몇 번으로 선택**해서 **누끼 / 지우기 / 배경 지우기**를 할 수 있어야 한다.
- 여러 이미지를 목록으로 관리하며 작업하고 **일괄 저장**할 수 있어야 한다.
- 저사양 PC와 데이터 제한 환경을 고려해 **경량 모델**만 사용한다 (모델 합계 약 85MB).
- 클릭 후 결과가 **즉시(0.1초 내외)** 갱신되어야 한다.

### 범위에서 제외 (1차 버전)

- 동영상 객체 분리
- 텍스트로 객체 지정 ("고양이만 따줘")
- 머리카락 한 올 단위의 정밀 매팅
- SAM 2 계열 모델 (입출력 형식이 다르고 111MB 이상)

## 3. AI 모델

### 사용 모델

| 역할 | 모델 | 파일 / 크기 | 라이선스 | 실행 장치 |
|------|------|------------|----------|-----------|
| 객체 윤곽 (선택) | MobileSAM 인코더 + SAM 디코더 | `models\mobile_sam\` 약 43MB | Apache 2.0 | 인코더 GPU 우선 / 디코더 CPU |
| 객체 자동 감지 | D-FINE-N (COCO 80종) | `models\dfine\dfine_n_coco.onnx` 14.8MB | Apache 2.0 | **항상 CPU** |
| 객체 지우기 (빠름) | MI-GAN 512 생성기 | `models\migan\migan-512-generator.onnx` 26.8MB | MIT | GPU 우선 |
| 객체 지우기 (고품질) | LaMa (OpenCV Zoo 변환본) | `models\lama\inpainting_lama_2025jan.onnx` 88.3MB | Apache 2.0 | **항상 CPU** (약 2초) |

모델 출처 (확인일 2026-10-06):
- MobileSAM / D-FINE: https://huggingface.co/nrl-ai/anylearning-labeling-models (`mobile_sam_20230629.zip`, `dfine_n_coco_956d170.zip`)
- MI-GAN: https://huggingface.co/FreeHugsForRobots/ps-inpaint-migan (원본 https://github.com/Picsart-AI-Research/MI-GAN)
- LaMa: https://huggingface.co/opencv/inpainting_lama (원본 https://github.com/advimman/lama)

모델은 프로그램의 **AI 모델 다운로드** 창(`ModelDownloadForm`, `Models/ModelDownloader`)이 위 주소에서 받는다. 사용자가 용량을 보고 [다운로드]를 눌러야 받으며, `.part` 임시 파일로 받은 뒤 완료되면 옮긴다 (zip은 필요한 파일만 풀기).

**Python 없이 C#(ONNX Runtime)만으로 동작한다.** PyTorch 가중치(.pt / .pth)는 C#에서 읽을 수 없으므로 쓰지 않고, 이미 ONNX로 공개된 모델만 사용한다 (2026-10-06 사용자 지시).

### 모델별 입출력

| 모델 | 입력 | 출력 |
|------|------|------|
| MobileSAM 인코더 | `input_image` float [H, W, 3] RGB 0~255 | `image_embeddings` [1, 256, 64, 64] |
| SAM 디코더 | `image_embeddings`, `point_coords` [1,N,2], `point_labels` [1,N], `mask_input` [1,1,256,256], `has_mask_input` [1], `orig_im_size` [2] | `masks`, `iou_predictions`, `low_res_masks` |
| D-FINE-N | `images` [1,3,640,640] RGB/255 (640×640으로 늘림), `orig_target_sizes` int64 [1,2] = [너비, 높이] | `labels` int64 [1,300], `boxes` [1,300,4] 원본 xyxy, `scores` [1,300] |
| MI-GAN | `gen_input` [1,4,512,512] = [mask−0.5, RGB(−1~1)×mask] (mask 1 = 남김) | `gen_output` [1,3,512,512] RGB (−1~1) |
| LaMa | `image` [1,3,512,512] RGB 0~1, `mask` [1,1,512,512] (1 = 지울 영역) | [1,3,512,512] RGB (0~1 또는 0~255 — 값 범위를 보고 자동 판별) |

### 주의사항 (CODEMAP 참고)

- **MobileSAM 인코더는 내부적으로 1024×682 캔버스를 쓴다.** 이미지를 캔버스에 비율 유지 + 왼쪽 위 배치 + 0 패딩으로 넣어야 좌표가 맞다 (CODEMAP 1번). `config.yaml`의 `max_width` / `max_height`로 읽는다.
- **D-FINE은 DirectML(GPU)에서 결과가 틀린다** → 항상 CPU (CODEMAP 3번). CPU로도 약 50ms.
- SAM 인코더와 MI-GAN은 CPU / GPU 결과가 같음을 확인했다.
- GPU 선택: 노트북의 DirectML 0번 장치는 내장 그래픽일 수 있어 DXGI로 전용 메모리가 가장 큰 GPU를 고른다.
- 검토 후 제외: OpenCV / OpenCvSharp (네이티브 런타임 60MB 이상, 기능이 이미 구현되어 있어 이득 적음), CUDA 실행 공급자 (1GB 이상 다운로드, NVIDIA 전용), LaMa fp32 원본 변환본 (약 200MB → 88MB인 OpenCV Zoo 변환본으로 대체).
- **LaMa는 DirectML(GPU)에서 실행 실패** (FFC의 MatMul 미지원) → 항상 CPU (CODEMAP 6번). CPU 결과 검증: 지운 자리 평균색 (102,186,189) ≈ 주변 (103,182,182) → 입력 색 순서 RGB 맞음, 출력 0~1.
- 오래 걸리는 작업은 0.3초가 지나면 "작업 중" 창(`BusyForm.RunAsync`)을 띄우고 끝나면 닫는다 (빠른 작업은 창 없음).

## 4. 처리 흐름

### 이미지 열기 → 선택

```
[이미지 / 폴더 추가] 끌어다 놓기 · 클릭 · Ctrl+O · 명령줄
     │  이미지 목록에 추가 (미리보기는 백그라운드 생성)
     ▼
[이미지 선택] 목록 클릭 → EditorDocument 생성 (작업이 있으면 유지, 없으면 전환 시 메모리 해제)
     ▼
[SAM 인코딩] 캔버스(1024×682) 레터박스 → 인코더 1회 → 임베딩 캐시
     │
     ├─[객체 자동 선택 (A)] D-FINE 감지(CPU) → 상자마다 SAM 박스 프롬프트 → 상자 밖 조각 제거
     │                      → 정리 / 확장·축소 / 페더 → "라벨 N" 이름으로 객체 목록에 추가 (실행 취소 1단계)
     │
     └─[수동 선택] 점(좌 포함 / 우 제외) · 박스 · 브러시
              → SAM 디코더 (이전 로짓을 mask_input으로) → 원본 크기 복원
              → KeepPromptedRegions(클릭 점 / 박스와 연결된 조각만) → 조각 제거 / 구멍 메우기
              → 브러시 레이어 덮어쓰기 → 오버레이 표시 → Enter로 객체 확정
```

### 편집과 저장

```
[객체 지우기 Del]   대상 마스크 확장(긴 변/150) → 주변 정사각형(최소 512) 잘라 512로 → MI-GAN 또는 LaMa(오른쪽 위 선택)
                    → 원래 크기 → 크게 늘어났으면 주변 질감 세기만큼 입자 추가 → 경계 블렌딩 (공통: CropInpainter)
[크기 조절 Ctrl+R]  고품질 바이큐빅 (확대 시 언샤프 선명화) + 객체 마스크도 같은 크기로 (실행 취소 가능)
[잘라내기 Ctrl+X]   복사 + 객체 지우기
[배경 지우기 Ctrl+B] 대상 마스크 밖 알파 = 0
[붙여넣기 Ctrl+V]   떠 있는 레이어(이동 / 크기) → Enter로 이미지에 합성
     │  모두 EditorDocument.ReplaceImage (실행 취소 가능) → 표시 갱신 → SAM 재인코딩
     ▼
[저장] 누끼 합성(자르기 / 배경색) → ImageExporter
        형식(PNG/JPG/BMP) · JPG 품질 · 크기(원본/비율 5~400%/긴 변) · 위치(원본 폴더\output / 지정 폴더)
[일괄 저장] 작업이 있는 모든 이미지: 객체별 누끼 + 편집한 이미지 → 이미지별 output 폴더
```

## 5. 솔루션 구조

```
NukkiStudio.sln
└─ src/NukkiStudio.csproj          (net10.0-windows, WinForms, 단일 프로젝트)
   ├─ Program.cs                   기본 폰트, 명령줄 인수(파일 / 폴더), 전역 예외 처리(error.log)
   ├─ MainForm                     메인 화면: 이미지 목록 · 캔버스 · 객체 / 보정 / 내보내기 카드
   ├─ ExportOptionsForm            내보내기 설정
   ├─ HelpForm                     도움말 (exe에 포함된 사용설명서.md를 간단한 마크다운 렌더링)
   ├─ AboutForm                    프로그램 정보 + 라이선스 전문 (Resources/Licenses/*.txt)
   ├─ ModelDownloadForm            AI 모델 설치 상태 / 다운로드 (진행률)
   ├─ ImageResizeForm              이미지 크기(해상도) 조절
   ├─ BusyForm                     오래 걸리는 작업의 "작업 중" 창 (경과 시간, 끝나면 자동으로 닫힘)
   ├─ Controls/
   │  ├─ ImageCanvas.cs            확대/축소/이동, 다크 스크롤 막대(확대 시), 축소 표시 단계별 캐시, 체커보드, 프롬프트, 브러시, 붙여넣기 레이어, 빈 화면 클릭
   │  ├─ CardPanel.cs              둥근 카드 + 제목
   │  ├─ FlatSlider.cs             플랫 슬라이더 (TrackBar 대체)
   │  ├─ ToggleSwitch.cs           토글 스위치 (CheckBox 상속)
   │  └─ BrushSizeStepper.cs       브러시 크기 + / − (누르고 있으면 반복) + 도구 모음용 ToolStripBrushSize
   ├─ UI/
   │  ├─ Theme.cs                  다크 색상표, 둥근 사각형, 다크 제목 표시줄(DWM)
   │  ├─ DarkToolStripRenderer.cs  메뉴 / 툴바 / 상태 표시줄 렌더러
   │  └─ IconFactory.cs            도구 아이콘을 코드로 그림 (외부 이미지 없음)
   ├─ Imaging/                     ImageBuffer, Mask, MaskOps, Compositor, ImagePreprocessor, BitmapConverter, OverlayRenderer, ImageResampler
   ├─ Segmentation/                ISegmentationModel, SamOnnxModel, ModelCatalog, OnnxSessionFactory, GpuAdapters, Prompt
   ├─ Detection/                   ObjectDetector (D-FINE), CocoLabels (80종 한국어)
   ├─ Inpainting/                  IInpainter, CropInpainter(공통 자르기 / 합성 / 입자), MiGanInpainter, LamaInpainter, DiffusionInpainter
   ├─ Models/                      ModelPackage(모델 목록 / 주소), ModelDownloader, AppPreferences(preferences.json)
   ├─ Export/                      ExportSettings (settings.json), ImageExporter
   ├─ Editing/                     EditorDocument, SegmentedObject, ImageItem
   └─ Resources/                   app.ico, Licenses/
```

- 픽셀 처리는 `Bitmap.LockBits` + `unsafe` / `Parallel.For`로 처리한다 (OpenCV 없이 직접 구현).
- 무거운 작업(인코딩, 감지, 지우기, 일괄 저장)은 `Task.Run`으로 UI와 분리하고, 실행 중에는 편집 입력을 막는다 (`_editBusy`).
- EditorDocument의 이미지 / 마스크 / 목록은 변경 시 새 인스턴스로 교체해 실행 취소 스냅샷이 참조만 공유한다 (최대 30단계).
- 브러시 레이어는 AI 마스크와 분리되어 있어 점을 더 찍어도 브러시 수정이 유지된다.

## 8. 기술 메모

- **.NET 10.0 (LTS)**: .NET 8 지원 종료(2026-11)로 사용자 승인 후 변경.
- **ONNX Runtime 네이티브 DLL**: `IncludeNativeLibrariesForSelfExtract=true`로 exe에 포함. DirectML 패키지의 pdb는 게시 후 삭제 (CODEMAP 2번).
- **디자이너 안전성**: 모델 로드 / 설정 읽기는 생성자의 `if (DesignMode) return;` 이후 또는 `Shown`에서. 코드 전용 공개 속성에는 디자이너 직렬화 숨김 특성 (CODEMAP 4번).
- **메모리**: 실행 직후 약 480MB (대부분 ONNX Runtime / DirectML). 작업 없는 이미지는 다른 이미지로 넘어갈 때 메모리에서 내린다.
- **VRAM 확인**: WMI 값은 4GB에서 잘리므로 `nvidia-smi`를 사용한다 (개발 PC 실제 6GB).
- **다운로드 용량** (개발 시 최초 1회): NuGet 약 330MB (DirectML 193MB 포함), .NET 10 런타임 팩 약 70MB, 모델 약 75MB. 배포물은 exe 65MB + 모델 85MB.
- **끌어다 놓기**: 프로그램과 탐색기의 권한 수준이 다르면 Windows가 막는다 (이 PC는 UAC 꺼짐 → 둘 다 관리자라 문제 없음).
