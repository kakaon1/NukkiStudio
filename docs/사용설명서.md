# Nukki Studio 사용 설명서

## 시작하기

Nukki Studio는 이미지 속 **객체(사람, 동물, 물건 등)를 AI로 찾거나 직접 선택**해서 다음 작업을 하는 프로그램입니다.

- **누끼 따기**: 선택한 객체만 배경 없이 저장 (PNG는 투명 배경)
- **객체 지우기**: 선택한 객체를 이미지에서 지우고, 그 자리를 주변 배경으로 자연스럽게 채우기
- **배경 지우기**: 선택한 객체만 남기고 나머지 배경을 투명하게 만들기
- **여러 이미지 일괄 작업**: 이미지 여러 장을 목록에 넣고 클릭해 가며 작업한 뒤 한 번에 저장

설치는 필요 없습니다. `NukkiStudio.exe`와 같은 폴더에 `models` 폴더가 있으면 바로 실행됩니다.

### AI 모델 다운로드

- 프로그램을 시작할 때 없는 AI 모델이 있으면 **AI 모델 다운로드** 창이 열립니다. 모델마다 용량이 표시되며, **[다운로드]를 눌러야만** 받습니다 (데이터 요금 주의).
- 받는 동안 진행률 막대와 **현재 모델 %, 받은 용량 / 전체 용량, 전체 진행률**이 표시됩니다. **취소**로 중단할 수 있으며, 반쯤 받은 파일은 남지 않습니다.
- **[나중에]** 를 누른 모델은 다음 시작부터 묻지 않습니다 (필수 모델인 MobileSAM은 없으면 항상 묻습니다). 나중에 받으려면 **설정 → AI 모델 다운로드 / 관리**를 엽니다.

| 모델 | 용도 | 용량 |
|------|------|------|
| MobileSAM | 객체 선택 (필수) | 약 35 MB |
| D-FINE-N | 객체 자동 선택 | 약 13 MB |
| MI-GAN | 객체 지우기 — 빠름 | 약 27 MB |
| LaMa | 객체 지우기 — 고품질 | 약 88 MB |

모든 기능은 프로그램(exe) 하나로 동작하며 Python 등 다른 프로그램을 설치할 필요가 없습니다.

### 기본 사용 순서

1. 이미지를 끌어다 놓거나 **열기**로 엽니다 (여러 장 가능).
2. **객체 자동 선택(A)** 을 누르면 AI가 객체를 찾아 오른쪽 **객체** 목록에 올립니다. 직접 고르고 싶으면 객체를 클릭하세요.
3. 목록에서 객체를 고른 뒤 원하는 작업을 합니다: **Ctrl+S** 저장(누끼) / **Del** 지우기 / **Ctrl+B** 배경 지우기
4. 여러 장이면 왼쪽 목록에서 다음 이미지를 클릭해 반복하고, 마지막에 **전체 일괄 저장**을 누릅니다.

## 이미지 열기와 이미지 목록

### 이미지 열기

- 이미지 파일이나 **폴더**를 프로그램 창 아무 곳에나 **끌어다 놓기** (폴더는 하위 폴더까지 모두 추가)
- 가운데 안내 영역이나 왼쪽 목록의 안내 문구를 **클릭**하면 파일 선택 창이 열립니다.
- 툴바 **열기** 또는 **Ctrl+O** (여러 파일 선택 가능), **폴더 추가**는 **Ctrl+Shift+O**
- 다른 프로그램에서 복사한 이미지를 새 이미지로 열기: **Ctrl+Shift+V**
- 이미지 파일을 `NukkiStudio.exe` 아이콘 위에 끌어다 놓아도 열립니다.

지원 형식: PNG, JPG, BMP, GIF, TIFF

### 이미지 목록 (왼쪽)

- 추가한 이미지가 미리보기와 함께 표시됩니다. 클릭하면 그 이미지로 바뀝니다.
- **PageUp / PageDown** 으로 이전 / 다음 이미지로 이동합니다.
- 이미지마다 작업(확정한 객체, 지우기)이 따로 유지됩니다. 다른 이미지로 갔다 와도 그대로 남아 있습니다.
- 상태 표시: **● 객체 2 · 편집됨** (저장할 작업 있음) / 작업 없음
- **빼기**: 선택한 이미지를 목록에서 뺍니다 (원본 파일은 지워지지 않습니다).

## 객체 선택

### 객체 자동 선택 (A)

- 툴바의 **객체 자동 선택** 버튼 또는 **A** 키를 누르면 AI가 이미지 속 객체(사람, 동물, 자동차, 가구 등 80종)를 찾습니다.
- 찾은 객체는 정확한 윤곽으로 다듬어져 **"사람 1", "개 1"** 처럼 이름이 붙어 객체 목록에 추가됩니다.
- 버튼을 눌렀을 때만 실행됩니다. 찾지 못한 객체는 아래 방법으로 직접 선택하세요.

### 점 선택 (Q)

- 객체 위를 **좌클릭**하면 그 객체가 파란색으로 선택됩니다.
- 덜 잡혔으면 빠진 부분을 **좌클릭**, 너무 많이 잡혔으면 빼고 싶은 부분을 **우클릭**합니다.
- 초록 점은 포함 점, 빨간 점은 제외 점입니다.

### 박스 선택 (W)

- 객체를 감싸도록 **드래그**하면 박스 안의 객체가 선택됩니다.

### 브러시 (E)

- 원하는 영역을 **직접 칠해서** 선택합니다. AI가 잘 못 잡는 부분을 칠해서 더할 때도 씁니다.
- 잘못 칠한 부분은 **마우스 오른쪽 버튼으로 드래그**해서 지웁니다.
- 칠한 뒤 원하는 기능을 누르면 됩니다: **Enter** 확정 / **Del** 지우기 / **Ctrl+B** 배경 지우기 / **Ctrl+S** 저장
- **브러시 크기**: 툴바의 브러시 버튼 옆 작은 **+ / −** 버튼 (누르고 있으면 계속 바뀜), 또는 **+ / −** 키 (**[** / **]** 도 가능). 오른쪽 **마스크 보정** 카드의 브러시 크기 슬라이더로도 조절합니다.
- **브러시 모양**: 툴바의 **● / ■** 버튼을 누를 때마다 **원형 ↔ 네모**로 바뀝니다. 네모는 반듯한 모서리나 직선 경계를 칠할 때 편합니다.
- 브러시 크기와 모양은 다음 실행 때도 유지됩니다.

### 선택 확정

- 선택이 마음에 들면 **Enter**(또는 **확정** 버튼)로 객체 목록에 추가합니다.
- **Esc**는 현재 선택을 취소합니다.

## 객체 목록

- 확정한 객체와 자동으로 찾은 객체가 오른쪽 **객체** 카드에 색깔별로 표시됩니다.
- 오른쪽 **눈 아이콘**을 클릭하면 화면에서 숨기거나 다시 보입니다 (목록에서 선택 후 **Space**도 가능).
- **목록에서 빼기**는 객체를 목록에서만 뺍니다 (이미지는 그대로).
- 저장 / 지우기 / 배경 지우기는 **목록에서 고른 객체**를 대상으로 합니다. 아무것도 고르지 않으면 현재 선택을 사용합니다.

## 객체 지우기 (Del)

선택한 객체를 이미지에서 지우고, 그 자리를 주변 배경으로 채웁니다.

1. 지울 객체를 목록에서 고르거나 클릭해서 선택합니다.
2. **Del** 키 또는 툴바의 **객체 지우기** 버튼을 누릅니다.
3. AI가 지운 자리를 주변과 어울리게 채웁니다.

- 결과가 마음에 들지 않으면 **Ctrl+Z**로 되돌립니다.

### 지우기 모델 고르기 (툴바 오른쪽 위)

툴바 오른쪽 위 **지우기 모델** 목록에서 고릅니다. 고른 모델은 다음 실행 때도 유지됩니다.

| 모델 | 특징 |
|------|------|
| MI-GAN (빠름) | 0.1초대로 빠름. 단순한 배경, 작은 객체에 적합 |
| LaMa (고품질) | 넓은 영역, 벽돌 / 풀밭 같은 반복 무늬 배경을 더 자연스럽게 채움. 한 번에 2~5초 (CPU) |

- 시간이 걸리는 작업(고품질 지우기, 객체 자동 선택, 크기 조절)은 **"지우는 중..." 창**에 진행 시간이 표시되고, 끝나면 창이 저절로 닫힙니다. 금방 끝나는 작업은 창이 뜨지 않습니다.

- 아직 받지 않은 모델은 목록에 **· 받기**가 붙어 있고, 고르면 다운로드 창이 열립니다.
- 고른 모델이 없으면 설치된 다른 모델로, 둘 다 없으면 기본 채우기 방식으로 지웁니다.
- 지운 자리가 비어 보이지 않도록 지울 영역을 테두리·그림자까지 조금 넓혀서 채우고, 크게 늘어난 부분에는 주변과 같은 질감(입자)을 더합니다.

## 이미지 크기(해상도) 조절 (Ctrl+R)

**편집 → 이미지 크기(해상도) 조절**에서 이미지의 픽셀 크기를 바꿉니다.

- 너비 / 높이를 직접 입력하거나 **50% / 100% / 150% / 200%** 버튼을 누릅니다. **가로세로 비율 유지**가 기본입니다.
- 키울 때는 고품질 보간(바이큐빅)과 선명화로 깔끔하게 늘립니다. 확정한 객체도 같은 크기로 맞춰집니다.
- **Ctrl+Z**로 원래 크기로 되돌릴 수 있습니다.
- 작업은 항상 **원본 해상도 그대로** 합니다. 화면에서 줄여 보일 때는 고품질로 축소해 표시하므로, 저장 결과는 원본 화질입니다.

## 배경 지우기 (Ctrl+B)

선택한 객체만 남기고 나머지를 투명하게 만듭니다.

- 목록에서 객체를 **하나 고르면 그 객체만** 남깁니다.
- 아무것도 고르지 않으면 **화면에 보이는(눈 아이콘이 켜진) 객체 전체와 현재 선택**을 남깁니다.
- 투명한 부분은 체커보드 무늬로 표시됩니다. **편집한 이미지 저장**(Ctrl+Alt+S)으로 저장합니다.

## 잘라내기 · 복사 · 붙여넣기

- **Ctrl+C**: 선택한 객체를 복사합니다 (배경 없이). 다른 프로그램에 붙여넣을 수 있습니다.
- **Ctrl+X**: 선택한 객체를 복사하고 이미지에서는 지웁니다 (배경으로 채움).
- **Ctrl+V**: 복사한 이미지를 **현재 이미지 위에** 붙여넣습니다.
  - 붙여넣은 이미지는 떠 있는 상태로 나타납니다. **드래그**로 위치를 옮기고 **Ctrl+마우스 휠**로 크기를 조절합니다.
  - **Enter** 또는 **더블클릭**으로 확정, **Esc**로 취소합니다.
  - 객체를 다른 이미지로 옮기려면: Ctrl+X(또는 Ctrl+C) → 왼쪽 목록에서 다른 이미지 클릭 → Ctrl+V
- 이미지가 열려 있지 않을 때 Ctrl+V를 누르면 새 이미지로 엽니다.

## 저장하기

| 기능 | 단축키 | 설명 |
|------|--------|------|
| 선택 객체 저장 | Ctrl+S | 목록에서 고른 객체(또는 현재 선택)를 배경 없이 저장 |
| 모두 저장 | Ctrl+Shift+S | 현재 이미지의 객체를 각각 별도 파일로 저장 |
| 편집한 이미지 저장 | Ctrl+Alt+S | 지우기 / 배경 지우기 / 붙여넣기 결과를 이미지 전체로 저장 |
| 전체 일괄 저장 | Ctrl+Shift+B | 목록의 모든 이미지 중 작업한 것을 한 번에 저장 |
| 선택 객체 복사 | Ctrl+C | 클립보드로 복사 |

- 저장 버튼을 누르면 **묻지 않고 내보내기 설정대로 바로 저장**합니다. 저장된 위치는 상태 표시줄에 표시되고, **파일 → 저장 폴더 열기**로 열 수 있습니다.
- **객체 크기로 자르기**: 객체 주변만 잘라서 저장합니다.
- **배경색 채우기**: 투명 대신 지정한 색으로 채웁니다.

### 내보내기 설정

내보내기 카드의 **설정** 버튼 (또는 **파일 → 내보내기 설정**)에서 정합니다. 설정은 다음 실행 때도 유지됩니다.

- **파일 형식**: PNG (투명 지원, 무손실) / JPG (용량 작음) / BMP (무압축)
- **JPG 품질**: 10~100 (높을수록 화질이 좋고 용량이 큼). JPG / BMP는 투명이 없어 투명한 부분은 흰색(또는 배경색)으로 채워집니다.
- **크기**: 원본 크기 그대로 / 비율 5~400% (100%보다 크면 고품질 확대 + 선명화) / 긴 변 최대 크기 (예: 2048px)
- **저장 위치**:
  - **원본 파일이 있는 폴더 안의 output 폴더** (기본값, 자동으로 만들어짐)
  - **지정한 폴더**
  - 붙여넣은 이미지처럼 원본 파일이 없으면 `사진\Nukki Studio\output`에 저장됩니다.
- 같은 이름의 파일이 있으면 `(2)`, `(3)`... 이 붙어 덮어쓰지 않습니다.

## 마스크 보정

오른쪽 **마스크 보정** 카드에서 선택 경계를 다듬습니다.

- **브러시 크기**: 브러시 도구의 크기
- **경계 부드럽게**: 저장할 때 경계를 부드럽게 (머리카락, 털 등에 유용)
- **확장 / 축소**: 선택 영역을 조금 넓히거나 좁힙니다. 지우기 결과에 테두리가 남으면 확장을 조금 올려 보세요.
- **작은 조각 제거 · 구멍 메우기**: 선택에 섞인 자잘한 점을 지우고 안쪽 빈 곳을 채웁니다.

## 화면 보기

| 기능 | 단축키 |
|------|--------|
| 원본 + 선택 표시 | F2 |
| 누끼 결과 미리보기 | F3 |
| 마스크만 보기 (흑백) | F4 |
| 화면에 맞춤 | Ctrl+0 |
| 실제 크기 (100%) | Ctrl+1 |
| 확대 / 축소 | 마우스 휠 |
| 화면 이동 | 아래 / 오른쪽 **스크롤 막대** 드래그 (빈 곳 클릭 = 그 위치로), 가운데 버튼 드래그, Space + 드래그 |
| 좌우 이동 | Shift + 마우스 휠 |

- 스크롤 막대는 확대해서 이미지가 화면보다 클 때만 나타납니다.

## 단축키 전체

| 단축키 | 기능 |
|--------|------|
| Ctrl+O | 이미지 열기 / 추가 (여러 개) |
| Ctrl+Shift+O | 폴더 추가 |

## 설정과 문제 해결

### 설정 메뉴

- **AI 모델 다운로드 / 관리**: 모델 설치 상태를 보고, 없는 모델을 받습니다.
- **AI 모델**: `models` 폴더에 있는 선택 모델 중 사용할 모델을 고릅니다.
- **실행 장치**: 자동(GPU 우선) 또는 CPU만 사용. GPU가 없거나 오류가 나면 자동으로 CPU를 씁니다. (객체 자동 선택은 정확도를 위해 항상 CPU로 실행됩니다)

### 자주 묻는 질문

- **"모델 없음"이 표시됩니다** — **설정 → AI 모델 다운로드 / 관리**에서 MobileSAM을 받으세요. 받은 모델은 `NukkiStudio.exe` 옆 `models` 폴더에 저장됩니다.
- **객체 자동 선택이 아무것도 찾지 못합니다** — 감지할 수 있는 객체는 사람, 동물, 차량, 가구, 생활용품 등 80종입니다. 그 밖의 객체는 클릭이나 박스로 선택하세요.
- **선택이 엉뚱하게 잡힙니다** — 빼고 싶은 부분을 우클릭하거나, 박스 도구로 범위를 먼저 지정하거나, 브러시로 칠해 보세요.
- **객체 지우기 결과가 흐릿하거나 비어 보입니다** — 오른쪽 위 지우기 모델을 **LaMa (고품질)** 로 바꿔 보세요. 테두리가 남으면 확장 슬라이더를 조금 올리거나, 여러 번 나눠서 지워 보세요.
- **오류 창이 떴습니다** — 프로그램은 닫히지 않고 계속 쓸 수 있습니다. 내용은 `%AppData%\NukkiStudio\error.log`에 기록됩니다.
- **끌어다 놓기가 안 됩니다** — 프로그램을 관리자 권한으로 실행했다면 탐색기도 같은 권한이어야 합니다 (Windows 보안 제한). 이 경우 열기 버튼이나 클릭으로 파일을 선택하세요.
- **느립니다** — 상태 표시줄 오른쪽에 GPU / CPU 중 무엇을 쓰는지 표시됩니다. 매우 큰 이미지는 처리 시간이 길어질 수 있습니다.
